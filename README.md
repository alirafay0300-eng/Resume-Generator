# 🧾 Resume Generator (Flask Web App)

A **Flask-based Resume Generator** that allows users to create and download professional resumes easily.
This web app is built with **Python (Flask)** for the backend and **HTML, CSS, and JavaScript** for the frontend.
Users can input their details, preview their resume, and download it in PDF or DOCX format.

---

## 🚀 Features

* 🧠 **Dynamic Resume Generation** – Input details through a simple form and get a formatted resume instantly.
* 🧩 **Flask Backend** – Handles form data, processes it, and renders resume templates dynamically.
* 🎨 **Responsive Design** – Built using HTML5, CSS3, and Jinja2 templates for a clean and modern look.
* 💾 **Download as PDF/DOCX** – Users can download their resume in multiple formats for job applications.
* ⚙️ **Customizable Templates** – Easily modify or add templates to change the resume design.
* 📅 **Date Formatting & Section Styling** – Headings include dates for a professional layout.

## ⚙️ Installation & Setup

1. **Clone this repository**

   ```bash
   git clone https://github.com/yourusername/resume-generator.git
   cd resume-generator
   ```

2. **Install dependencies**

   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Flask app**

   ```bash
   python app.py
   ```

4. **Open your browser and visit**

   ```
   http://127.0.0.1:5000
   ```
